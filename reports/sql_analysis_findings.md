# H&M SQL 导出结果分析

分析日期：2026-11-09。基于现有24份 SQL 导出 CSV，核对对应 SQL 后计算；本次未重跑数据库，也未分析 Python 模型。数据观察期为2018-09-20至2020-09-22。

## 分析口径与核验

- 一条交易记录按一件购买商品统计，不是订单。没有订单编号，不能计算订单量、客单价或每单件数。
- 销售额是标准化价格之和，本文不赋予人民币等货币单位；不是利润。
- 所有结果仅描述这个数据集，不能代表H&M全部市场，也未确认具体国家。渠道暂保留代码1、2。
- 首购指数据中首次观察到购买；不同日期的再次购买才算复购。客户年龄来自静态客户表，不能保证是购买当时年龄。
- 30/90/180天复购率分别排除缺乏对应完整后续观察窗口的客户。
- 季节按代码划分：3—5月春、6—8月夏、9—11月秋、12—2月冬。这是分析定义，不能据此确认客户所在地气候。
- 2018年9月和2020年9月不完整。观察期内规模、占比不能直接解释为年度指标。

这些核验支持已导出表之间的一致性，不替代对原始数据库的重新检查。

104,547个有成交商品按销售额排序后，前约10%的10,455个商品贡献61.67%销售额；前约20%贡献80.60%；前约30%贡献90.13%。排名后约50%的商品合计仅贡献约2.37%。

可提出优先监控头部商品的销售与供货情况。不能直接淘汰长尾商品：缺少上市时间、库存、成本、毛利，低销售可能受曝光时长和供货影响。十分位基于有成交商品，不包含995个未观察到交易的商品。

### 3.7 monthly_product_type_performance.csv：拆解细分类增长

关系式：销售额=有成交商品数×每个成交商品平均销量×平均每件成交价格。

以Sweater的2019年8月至9月为例：

| 指标 | 8月 | 9月 | 变化 |
|---|---:|---:|---:|
| 标准化销售额 | 2,154.129 | 6,170.248 | +186.44% |
| 购买件数 | 85,275 | 195,242 | 约+128.96% |
| 有成交商品数 | 2,620 | 3,171 | +21.03% |
| 每个成交商品平均购买件数 | 32.5477 | 61.5711 | +89.17% |
| 平均每件成交价格 | 0.025261 | 0.031603 | +25.11% |

增长同时伴随成交商品范围扩大、单品平均销量提升和平均成交价格上升，其中单品平均销量的变化尤其明显。这是指标分解，三项增长率是乘法关系，不能直接相加，也不能据此归因于上新或提价。

articles_sold不代表全部上架商品数；units_per_article不是售罄率或库存周转率。现有表有32处相邻结果跨过无记录月份，相关LAG增长率应标记为与上一有记录月比较，不能直接当月环比。

## 04 客户复购：9份导出结果

来源：`../results/repurchase_analysis/`（不包括前述两张月度销售表）。

### 4.1 customer_repurchase_overview.csv：购买是否发生在多个日期

1,362,281位观察期成交客户中，447,973人只在一个日期购买，占32.88%；914,308人在多个日期购买，占67.12%。

这说明多数成交客户在观察期内出现再次购买。它不是统一30天复购率，各客户可观察时长不同；不能将单日购买直接称为流失，也不能把一个购买日称为一个订单。

### 4.2 second_purchase_interval_summary.csv：复购间隔有长尾

在914,308位已观察到复购的客户中，首次至第二次购买平均间隔90.59天，中位数44天。平均值明显高于中位数，说明较长间隔拉高平均值，中位数更适合描述这组已复购客户的典型间隔。

这不意味着所有客户都会在44天内复购。未发生复购的客户未进入计算；该统计也未校正观察截止造成的截尾，不能视为全体客户潜在等待时间的无偏估计。

### 4.3 second_purchase_interval_distribution.csv：复购速度分布

| 首次至第二次购买间隔 | 人数 | 占已复购客户比例 |
|---|---:|---:|
| 1—7天 | 169,268 | 18.51% |
| 8—14天 | 82,072 | 8.98% |
| 15—30天 | 127,911 | 13.99% |
| 31—60天 | 150,240 | 16.43% |
| 61—90天 | 93,598 | 10.24% |
| 91—180天 | 145,204 | 15.88% |
| 181天及以上 | 146,015 | 15.97% |

约41.48%的已复购客户在30天内第二次购买，约57.91%在60天内。比例由人数合计重新计算，可能与已四舍五入的分组百分比之和相差0.01个百分点。

41.48%不是整体30天复购率：分母是已复购客户，且这张表未按完整30天窗口筛选。可探索首购后7/14/30天触达实验，但这些分组宽度不同，不能仅按柱高判断每天复购倾向，更不能直接认定最优触达日期。

### 4.4 customer_repurchase_rates.csv：统一观察窗口后的复购

| 窗口 | 符合完整观察条件的客户数 | 复购率 |
|---|---:|---:|
| 30天 | 1,338,029 | 28.13% |
| 90天 | 1,291,147 | 47.07% |
| 180天 | 1,189,917 | 59.95% |

30天内有376,347人复购。较长窗口对应更高累计复购比例，但三组客户分母不同，不应相减后解释为同一组客户在第31—90天新增复购的比例。若要比较同一组客户随时间变化，应统一使用具有180天观察窗口的客户重新计算。

### 4.5 monthly_cohort_repurchase_rates.csv：按首次观察购买月份比较

早期月份30天复购率较高：2018年9月45.03%，10月38.08%，11月31.24%，12月26.65%。2019年内各月在17.83%—25.75%之间波动；2020年4月17.97%，5月回升至23.72%，6月23.31%。

可描述不同首购月份客户群的表现差异，但不能直接断言获客质量持续恶化。观察期开头可能包含实际早已购买过的老客户；随时间推移，“首次被观察到”的客户集合也在变化。这种构成差异无法仅靠这张表消除。

最新月份注意：2020年8月22,974位首购客户中只有16,260位满足30天窗口，18.78%仅代表这一部分；9月17,538位均不满足30天窗口，NULL正确。2020年3月180天、6月90天也只有部分客户符合观察条件。制图时标记部分覆盖，不把NULL画成0。

大部分销量来自客户首次观察购买日之后的购买，支持把复购与客户维护作为重要分析方向。同一客户首购日与之后日期分别归入两组，这不是两个互斥的客户群；较长观察期本身也给后续购买更多累计机会，不能用84.25%推断留存活动的增量收益。

## 报告中建议优先呈现的结论

1. 基础表键唯一、交易关联完整、日度记录连续，已导出结果的主要总量能够互相核对。
2. 2020年1—8月销售额同比下降11.95%、件数下降13.02%，销售规模下降主要伴随购买件数减少。
3. 渠道2贡献75.62%的销售额，2020年3—5月渠道结构变化突出，应单独检查渠道1四月缺记录的原因。
4. 上身、下身、全身服装三大类合计约79.04%销售额；季节与渠道之间的品类结构不同。
5. 前约10%的有成交商品贡献61.67%销售额，前约20%贡献80.60%，销售集中度高。
6. Sweater在2019年9月销售额环比增长186.44%，伴随成交商品范围、单品平均销量和均价共同上升。
7. 观察期内67.12%成交客户在多个日期购买；完整30天窗口复购率为28.13%。两者口径不同。
8. 已复购客户的第二次购买间隔中位数44天、均值90.59天，存在较长间隔。
9. 首购渠道1、25—34岁和首购上身服装群体的30天复购率相对较高，但分组差异不是因果效果。
10. 首次观察购买日之后的交易贡献84.41%件数和84.25%销售额，后续购买是样本的重要销售来源。
